# Context

On 2026-11-12 three AI features were built, each one request to a paid AI API per use, with
`ANTHROPIC_API_KEY` on Netlify, for signed-in accounts only:

- #98 / #110: Hanna asked for patterned page edges with an option to describe them "and have them
  generated by an AI" (*Describe it*).
- #111: *Recommended for you* (asked for in chat).
- #114: *Find the rest* in *Complete your series*.

The same day #117 ("No AI anywhere", asked for in chat) removed every AI request and kept the
features working without: page edges from the cover or by hand, recommendations and series from
Open Library. The Anthropic SDK, the shared AI helper and the three AI server functions went, and
the key was no longer needed. The roadmap (#21) recorded it as "No AI anywhere".

The pull request doesn't say who asked. It removed a paid outside service and its key, which is
the Engineer's to decide (G-0009), and the Engineer merged it, so it is recorded as his.

Hanna asked on 2026-11-19 (#183) for AI to come back for completing series, page edges, quotes and
back texts; that is open question Q-002.

Global decisions: this follows G-0009 (what costs money needs the Engineer) and the guardrails'
"Needs Sander" group for paid services. No overrule.

# Decision

- The app makes **no requests to AI services**, holds no AI key, and has no AI dependency.
- Features that once used AI work without it: page edges from the cover or picked by hand, lookups
  through Open Library.

# Rationale

Every AI request costs money, billed to the Engineer, and needs a secret on Netlify; the features
work well enough without.

# Consequences

- Bringing any AI back is a replacing decision, through Q-002 or a new question for the Engineer.

# Guidance for agents

- Don't add an AI SDK, an AI API call or an AI key, also not "optional" or behind a missing key,
  until the Engineer has answered Q-002 or a new question.
- Prefer free sources that need no key (Open Library) and fail quietly.
